# AR-009 — Structure-aware guideline extraction

Adds a deterministic HTML-to-text extractor preserving section heading markers, table row boundaries, cell delimiters and inline footnote markers. This is a **formatting improvement only**, not a clinical parser.

## Review criteria
- Verify tables against the official rendered page, including row/column spans and headers.
- Verify footnote relationships, hyperlinks and contextual qualifiers.
- Confirm document publication/revision metadata independently.
- Never treat extracted content as validated prescribing guidance.

## Limitations
Complex tables with colspan/rowspan, nested tables, dynamic JavaScript content, hidden elements, and footnote links are **not** reliably represented. No external source is fetched by these tests. Evidence still requires operator review and is not clinically certified.
