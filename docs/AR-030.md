# AR-030 — Local research audit trail

A JSONL event log with monotonic sequence numbers and SHA-256 chaining records `manifest_registered`, `review_decision_recorded`, and `evaluation_changed` events. Events include release ID, artifact digest, optional pseudonymous actor, timestamp, and previous event digest.

```bash
python -m scripts.research_audit --path local/research-audit.jsonl append --event-type manifest_registered --release-id research_001 --artifact-sha256 <64-character-digest>
python -m scripts.research_audit --path local/research-audit.jsonl list --release-id research_001
```

The reader rejects invalid entries, sequence gaps, altered hashes, or missing middle events. The file is stored under Git-ignored `local/`. There is no external service, automated deployment or clinical data.

**Limitations:** local files are not append-only at the operating-system level, concurrent writers are not serialized, the last event can be deleted without detection unless its digest is stored independently, and a privileged writer can rewrite the entire chain. Pseudonymous actor IDs are not authenticated. Use protected storage, locking and externally anchored head hashes for stronger provenance in a future milestone.
