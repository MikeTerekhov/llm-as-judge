# AR-037 — Integrated research overview and README refresh

Added `/judge/overview`, a read-only Next.js page that fetches four existing research endpoints in parallel: adversarial lexical screening, offline model benchmark status, operator-enabled synthetic adjudication and conservative research quality gates. Every section has its own loading, available and unavailable state. Missing data is never treated as a passed quality gate or as a model verdict.

Added navigation links from the homepage and `/judge`, a responsive dashboard stylesheet, and a complete root README covering architecture, available modules, local startup, research API routes, testing, security boundaries and current limitations.

Start the API with `python -m uvicorn api.app:app --reload --port 8000`, start Next.js with `cd frontend && npm run dev`, and open `http://localhost:3000/judge/overview`. Human-review and gate panels require the disabled-by-default local review configuration.

No external LLM invocation, write operations or clinical decisions are added.
