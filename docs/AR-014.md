# AR-014 — Model comparison scaffold

Adds a side-by-side lexical/model comparison function for the six synthetic benchmark examples, plus read-only GET /api/v1/judge/comparison.

The default endpoint **never invokes a model** and returns `null` for disagreement rate, not a misleading zero. An explicit callable may be supplied to `compare(examples, model_call)` in offline experiments, with a mock or separately configured provider. Model outputs are schema-validated by AR-012. A disagreement is an operational mismatch between lexical and model screening, not a measure of medical correctness.

There is deliberately no dashboard-controlled external model switch, no model credentials in frontend, and no real patient input. The API remains synthetic and fail-closed.

Future work: independently labeled adversarial examples, safe opt-in server-side model execution with privacy review, and expert-adjudicated model performance metrics.
