# AR-035 — Side-by-side evaluator comparison

The interactive demo's Evaluation step now has **Load model comparison**, a read-only request to `GET /api/v1/judge/adversarial-model`. It presents the canonical fictional author labels, lexical screening statuses, and optional model verdicts in a single table.

The existing endpoint runs **no external model**. In the default configuration all model verdicts are absent and displayed as **Not run**, with zero returned verdicts and twelve abstentions. This is intentional and must not be mistaken for an evaluation score or a model's negative prediction. No clinical adjudication or medical validation is claimed.

To try it, start the backend with `python -m uvicorn api.app:app --reload --port 8000` and the frontend with `cd frontend && npm run dev`. Open `http://localhost:3000/demo`, go to Evaluation, then click **Load model comparison**. If the backend is offline, the guided demo remains usable. The JSON export includes model comparison availability and returned-verdict count.
