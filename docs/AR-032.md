# AR-032 — Interactive Demo Mode

The new `/demo` route is a self-contained, responsive four-step walkthrough of AI Regimen. It works with only the Next.js frontend, without an API server, model key, review JSONL or preloaded research history.

## Run

```bash
git checkout feature/ar-032-interactive-demo-mode
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000/demo` or use the new homepage link.

1. **Overview:** fictional negation example shows how overlapping words can contradict.
2. **Evidence challenge:** classify six real synthetic fixtures from `clinical/adversarial_fixtures.py`, reveal explanations and switch cases.
3. **Evaluation:** compare author labels with **illustrative simulated** lexical results; these are not live model predictions or measured evaluator accuracy.
4. **Research governance:** inspect an **illustrative, in-memory** blocked quality gate and simulate pending/rejected audit events. No data is persisted or approved.

The demo fixture JSON is checked against the Python source by `tests/test_interactive_demo.py`. The page does not fetch data, send requests, call a model, store PHI or create real audit records. It does not provide diagnosis or treatment recommendations.

The research dashboards under `/judge` continue to use the backend and may require local operator opt-in settings.
