# AR-033 — Offline demo results export

The self-contained `/demo` walkthrough now lets visitors download a JSON report after answering at least one fictional evidence challenge. The report includes all six canonical fixture IDs, authored semantic labels, participant choices (or null if unanswered), explanation-reveal status, and whether the response matches the fictional author label. It includes explicit research and clinical limitations.

Run `cd frontend && npm install && npm run dev`, then open `http://localhost:3000/demo`, complete some evidence challenges, continue to **Evaluation**, and choose **Download results (.json)**.

The export uses a browser Blob and a local download link. It does not upload answers, call an LLM, or store information in a backend. This is a presentation aid, not a validated model benchmark or patient record.
