# AR-023 — Reproducible synthetic evaluation reports

Generate a versioned JSON research report combining fictional adversarial fixture results, human review coverage, inter-rater reliability and benchmark quality gates.

```bash
python -m scripts.generate_evaluation_report --reviews local/reviews.jsonl --output local/evaluation-report.json --experiment-id trial-1
python -m scripts.generate_evaluation_report --require-pass
```

The report contains schema version 1.0, a SHA-256 fingerprint of the canonical synthetic fixture data, a SHA-256 fingerprint of per-case review label counts, the quality policy and a SHA-256 checksum of the report itself. The report is deterministic for identical inputs, including when review order changes. It deliberately omits reviewer identities, free-text notes and timestamps. Per-pair Cohen statistics are anonymized, although small research cohorts can still permit inference; treat reports as internal.

`--require-pass` exits nonzero when quality checks fail, even though a blocked report is still written for auditing. No LLM is called. This is an evaluation provenance artifact, not clinical validation or independent semantic ground truth.

The report checksum detects modification but is not a digital signature or proof of provenance. Reproducibility additionally requires the same code version; record the Git commit SHA in your external experiment log.
