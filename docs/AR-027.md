# AR-027 — Research evaluation release readiness

Combines three independent checks into one fail-closed decision: integrity of the AR-023 report checksum, all human review quality gates, and a regression comparison bound to the exact current report SHA-256. The only positive outcome is `ready_for_manual_research_review`; no deployment, promotion, or clinical approval occurs.

```bash
python -m scripts.check_release_readiness --report local/evaluation-report.json --regression artifacts/evaluation-regression.json
```

The command writes a JSON assessment and exits nonzero when blocked. `--allow-missing-regression` is for local diagnostics only, not release approval. No clinical data, model calls or network access are required.

The CI synthetic report contains no human reviews, so its release readiness **must remain blocked** even if reproducibility and regression checks pass. This is intentional. An unauthenticated checksum does not prove provenance; manual research review and independent validation remain necessary.
