# AR-042 — Persistent local experiment history

This milestone adds durable **local JSON history** for AR-039 executed fictional model benchmark reports. The storage is intentionally not exposed as a web API and does not call external models.

```bash
python -m scripts.experiment_history --history local/model-evaluation-history.json add results-model-a.json
python -m scripts.experiment_history --history local/model-evaluation-history.json add results-model-b.json
python -m scripts.experiment_history --history local/model-evaluation-history.json list
```

Each entry contains a timezone-aware recording timestamp, SHA-256 checksum and the full original executed benchmark report. Writes use a temporary file followed by atomic replacement; existing records are retained, exact duplicate reports rejected, and tampering detected on read. Limits: 200 runs and 2 MiB per history file. One writer at a time is assumed; this is not a concurrent database.

The loader verifies that each run contains the **same twelve fixed fictional adversarial fixture IDs and authored labels** currently defined in the repository. The `list` output is chronologically sorted and shows model name, verdict coverage, returned verdict count and conditional authored-label agreement. This does not demonstrate clinical accuracy or statistical significance.

Do not commit history files containing sensitive information. This feature does not integrate the web dashboard with local history storage; it is a CLI-first persistence foundation for a later authenticated research history UI.

Test with `python -m unittest discover -s tests -v`.
