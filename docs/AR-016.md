# AR-016 — Local synthetic experiment history

Adds metadata-only JSONL history for explicitly opted-in synthetic model evaluations. Run IDs, model identifiers, timestamps, aggregate disagreement metrics and per-fixture dispositions are recorded. No prompts, excerpts, case data, API keys or raw model rationales are stored.

Use `python -m scripts.run_recorded_comparison --history local/experiments.jsonl` after configuring the AR-015 environment variables. Without explicit opt-in, the command refuses to run. History is local only; the public API/dashboard do not expose it.

The history file is **not encrypted**, and symlink checks alone do not make concurrent writes, path traversal or filesystem races safe. Run only in a trusted local environment with appropriate file permissions. Never use patient data. Disagreement rates measure operational screening differences, not medical accuracy.
