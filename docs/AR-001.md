# AR-001: Clinical foundation

Status: research prototype; synthetic cases only.

## Scope
- Immutable, typed clinical-case schema
- Reject explicitly non-synthetic cases
- Missing-context warnings and abstention before regimen assessment
- Evidence retrieval interface with an empty default provider
- Unit tests for validation and safety behavior

## Non-goals
No diagnosis, regimen selection, drug interaction decision, clinical deployment, PHI processing, or claim of regulatory compliance. The existing educational judge in `main.py` remains separate and unchanged.

## Important limitations
The `synthetic` flag is a declaration, not a reliable PHI detector. Do not submit real patient information. The readiness flag only means required demo fields are populated; it does not indicate clinical suitability or safety. No clinical rules or live guideline retrieval are implemented.

## Run tests
```bash
python -m unittest discover -s tests -v
```
