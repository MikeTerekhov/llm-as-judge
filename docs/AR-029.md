# AR-029 — Local research release registry

An append-only-by-convention directory of AR-028 manifests, with exclusive file creation to avoid overwriting existing release IDs. The registry verifies each manifest checksum and exposes a small metadata index, filterable by manual decision or full commit SHA.

```bash
python -m scripts.release_registry --directory local/release-registry add --release-id research_001 --manifest local/release-manifest.json
python -m scripts.release_registry --directory local/release-registry list --decision pending
```

Release IDs must contain only letters, digits, underscores and hyphens. Duplicate IDs are rejected. Files are stored under `local/`, which is Git-ignored. The index omits reviewer pseudonyms, but individual stored manifests may contain them; protect the local directory accordingly.

This is not tamper-evident storage against a filesystem administrator: checksums can be recomputed, entries can be deleted externally, and approvals are self-asserted. There is no remote API, release publishing, clinical validation, or automated deployment.
