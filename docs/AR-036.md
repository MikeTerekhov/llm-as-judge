# AR-036 — Optional human-review comparison in the guided demo

The Evaluation step can now load local synthetic human-review summaries alongside authored fixture labels, deterministic lexical screening and optional model benchmark status. It displays per-case reviewer counts, consensus (when available), disputes, and second-review needs, without reviewer identifiers or notes.

This is a read-only, explicitly operator-enabled feature. Start the FastAPI backend with:

```bash
AI_REGIMEN_ENABLE_REVIEW_API=true AI_REGIMEN_REVIEW_PATH=local/reviews.jsonl python -m uvicorn api.app:app --reload --port 8000
```

Then run `cd frontend && npm run dev`, open `http://localhost:3000/demo`, choose Evaluation and **Load human review status**. A missing, disabled or unconfigured review API leaves the offline demo usable. The JSON export records review availability and the aggregate number of reviewed examples.

Reviewer unanimity is not accuracy. Only fictional cases are permitted. This interface does not create review entries or display reviewer identities, timestamps, or notes. It is not a clinical decision-support system.
