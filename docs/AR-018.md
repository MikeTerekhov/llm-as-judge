# AR-018 — Adversarial synthetic evaluation dataset

Adds twelve hand-authored fictional claim/evidence pairs covering negation, exact quantities, uncertainty, quantifier scope, temporal mismatches, entity swaps and causal overreach. No patient data, treatments or medical recommendations.

`GET /api/v1/judge/adversarial` returns lexical screening behavior alongside the hand-authored semantic expectations. `potential_false_assurance_count` measures cases where a lexical REVIEW_REQUIRED screen overlaps a non-supported semantic label. It is **not** a clinical error rate, and REVIEW_REQUIRED never means clinical approval.

These labels have not been independently adjudicated. No external model is called. Future work can add a separate, opt-in LLM evaluation against these same cases, plus independent human annotation and inter-rater agreement.
