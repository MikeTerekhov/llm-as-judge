# AR-011 — Synthetic judge benchmark scaffold

This milestone introduces reproducible benchmark scoring for the existing deterministic claim screener. It reports accuracy, confusion counts and per-category accuracy over six **hand-authored synthetic examples**: overlap, fabricated citation, unsupported terms, negation, missing citation and blank claim.

Run:
```bash
python -m unittest discover -s tests -v
python -m scripts.run_judge_benchmark
```

The fixture's expected labels are defined to test the screener's behavior. Therefore high fixture accuracy **does not** demonstrate real-world performance, semantic entailment, clinical validity, or model superiority. There is **no external LLM-as-judge implementation** yet. Future evaluation requires independently labeled examples, harder contradiction/negation cases, blinded expert adjudication, precision/recall, and calibrated abstention thresholds.
