# AR-005 — Controlled guideline ingestion

Research-only prototype. This milestone adds an **opt-in CLI** to fetch one explicitly selected HTTPS page from the existing NIH/FDA hostname allowlist and write an offline snapshot for manual review.

## Run
From repository root:
```bash
python -m unittest discover -s tests -v
python -m scripts.ingest_guideline --url https://clinicalinfo.hiv.gov/en/guidelines --document-id NIH-REVIEW --title "Guideline review snapshot" --version "VERIFY-MANUALLY" --published-on 2026-01-01 --output local-guideline-snapshot.json
```
The CLI example's metadata is illustrative, **not verified**. Inspect the source's actual publication/revision date and content before use. Do not commit downloaded source text without reviewing copyright and licensing.

## Controls
- Only allowlisted HTTPS hosts; no URL queries, credentials, ports, or redirects.
- Strict HTML content-type, UTF-8, response size and text-length limits.
- SHA-256 digest, version and timestamps for offline audit.
- No automatic source fetching in the API; no treatment suggestions.

## Limitations
Hash verification proves only that the saved text matches its digest. The code does not cryptographically authenticate NIH/FDA content, verify operator-entered revision dates, validate HTML extraction quality, or assess clinical correctness. The current extractor flattens HTML and may lose tables, footnotes and contextual structure, making it unsuitable for clinical decisions. Do not expose this fetcher as a public endpoint. Review sources and legal terms manually, and require expert verification before any clinical use.

Future: reviewed snapshots, source-specific parsers preserving tables, scheduled change detection, signed manifests, and clinician approval workflows.
