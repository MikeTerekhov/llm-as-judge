# AR-003 — Grounded assessment scaffolding

Research prototype; synthetic cases only.

## Implemented
- Typed claims and assessment statuses.
- Evidence retrieval gated on completeness checks from AR-001.
- Abstention when evidence is missing/stale or claim generation fails.
- Rejection of blank claims and invented document identifiers.
- Optional generator interface for future model integration, defaulting to no claims.
- Seven synthetic unit tests.

## Critical limitations
The validator checks only that citation IDs exist among retrieved hits. It **does not** establish that a claim is entailed by its cited text, that sources are authentic, or that the clinical statement is safe. An `evidence_review` status means a human must check the claim, not that it is clinically endorsed. No LLM API calls, treatment suggestions, drug interaction rules, or real patient data are supported.

Before any clinical use, implement claim-level entailment verification, deterministic medication checks, expert adjudication, evaluation on clinician-curated cases, security/privacy controls, and regulatory review.
