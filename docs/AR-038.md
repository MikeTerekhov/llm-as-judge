# AR-038 — Semantic classification metrics

Adds reusable, abstention-aware evaluation of optional LLM verdicts against the twelve hand-authored fictional adversarial labels. The `classification` object on `GET /api/v1/judge/adversarial-model` now includes verdict coverage, conditional accuracy, macro F1, per-label precision/recall/F1, and a 3×3 confusion matrix. The adversarial dashboard displays these metrics when available.

Metrics count only returned valid verdicts. When no model is configured, coverage is 0, while accuracy and F1 are unavailable (null), not zero. Missing support or predictions yield undefined per-label metrics rather than misleading zero denominators. Macro F1 averages only defined class F1 values.

These metrics quantify agreement with fictional, authored expectations, not independent medical correctness. No model provider is called by the endpoint. A future milestone can add an explicit, secured, opt-in evaluation runner and independently reviewed dataset.

Verify with `python -m unittest discover -s tests -v` and `cd frontend && npm run build`.
