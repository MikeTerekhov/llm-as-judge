# AR-038 — Sentence-level NLI semantic screening

Lexical screening (`clinical/claim_judge.py`) only checks that a claim's words appear in its cited excerpts. It cannot tell "The beacon is active" from "The beacon is not active". This milestone adds an optional **natural language inference (NLI)** check that estimates whether cited text entails, contradicts or is neutral toward a claim.

## How it works

`clinical/semantic_judge.py` splits each cited excerpt into sentences and scores every (sentence, claim) pair with a pluggable `NLIScorer`. It returns probabilities for entailment, neutral and contradiction.

| Condition | Verdict | Disposition |
| --- | --- | --- |
| No valid citation, no scorer, or scorer failure | none | `abstain` |
| Any cited sentence contradicts at ≥ 0.9 | `contradicted` | `flagged` |
| No single sentence entails at ≥ 0.9 | `insufficient_evidence` | `flagged` |
| Entailed, but lexical screening flagged the claim | `supported` | `flagged` |
| Entailed and lexical screening passed | `supported` | `human_review_required` |

Design choices:

- **Contradiction wins.** If any cited sentence contradicts the claim, it is flagged even when another sentence supports it.
- **One sentence must carry the claim.** Claims that need several sentences combined are reported as insufficient rather than guessed at. The supporting or conflicting sentence and its document ID are returned so reviewers can see why.
- **Nothing is auto-approved.** As with the LLM judge, `supported` still requires human review, and both screens must agree.
- **Fails closed.** Scorer exceptions or malformed scores produce an abstention, not a verdict.

## Running a real model

The default backend (`clinical/nli_backends.py`) runs a local Hugging Face cross-encoder (`cross-encoder/nli-deberta-v3-base`) on CPU. No claim or evidence text leaves the machine. The dependencies are optional:

```bash
pip install -r requirements-nli.txt
python -m scripts.run_semantic_benchmark --allow-download --revision <commit-hash>
```

The script refuses to download unless `--allow-download` is given. Pin `--revision` for reproducible results. The report includes a confusion matrix, per-category agreement, `false_support_count` (the safety-relevant error: calling an unsupported claim supported) and the lexical screen's false-assurance count for comparison.

## Limitations

The 12 adversarial fixtures are far too few to establish accuracy. Thresholds are untuned defaults. General-domain NLI models are not validated on clinical text, and entailment is not clinical correctness. The check is not yet wired into the assessment pipeline, API or dashboards. Tests use a deterministic stand-in scorer, so they verify the decision logic, not any model's quality.
