# AR-012 — Opt-in LLM-as-judge adapter

Adds a model-agnostic callable interface and optional HTTPS OpenAI-compatible chat-completions transport. The default is **no model call**, no network, and abstention. The existing API is not wired to this adapter and continues to generate no claims.

The model receives only explicitly supplied claim text and cited excerpts, **never a clinical case**. Only synthetic/non-sensitive fixtures may be sent to third-party model providers. This does not detect PHI automatically.

Model responses must be bounded JSON with an allowlisted verdict and known citation IDs. Errors fail closed. A model verdict of `supported` can only produce `human_review_required`, never approval. Unsupported or contradictory responses are flagged. The lexical baseline may disagree with a semantic model; disagreement remains flagged.

## Optional external transport

`make_chat_transport(endpoint="https://YOUR-EXPLICIT-ENDPOINT/v1/chat/completions", model="YOUR-MODEL", api_key="YOUR-KEY")` returns a callable. No credentials are stored in the repo. Never send patient data. Review vendor retention, privacy and model terms first.

## Known limitations

LLM judgments are not trustworthy clinical entailment proofs. Prompt injection, hallucinations, semantic contradictions, provider data retention, and unsupported claims remain risks. A configured endpoint may redirect; do not use untrusted endpoints. Add independent labeled benchmarks and human adjudication before interpreting accuracy.
