# AR-039 — Opt-in external model benchmark runner

The existing `clinical/openai_compatible_judge.py` HTTPS transport is now wired to a bounded command-line runner for the **12 fixed, fictional adversarial fixtures**. No API endpoint or UI triggers external model calls. The default is dry-run and makes zero network requests.

Dry-run:

```bash
python -m scripts.run_adversarial_model
```

Explicit execution (may incur provider charges):

```bash
export AI_REGIMEN_MODEL_API_KEY="your-provider-key"
python -m scripts.run_adversarial_model --execute \
  --endpoint https://api.openai.com/v1/chat/completions \
  --model YOUR_CONFIGURED_MODEL \
  --output local-model-report.json
```

Only execute with an operator-approved endpoint and account. The transport enforces HTTPS, rejects redirects and limits response size and request timeout. The runner refuses to overwrite an existing output. Each fixture is sent separately, so up to 12 external calls are possible; invalid model output or transport errors produce an abstention rather than a fabricated verdict. The output contains no API key, but may contain model judgments and fictional fixture metadata.

Reports contain conditional agreement accuracy, macro F1, per-label precision/recall/F1, confusion counts and abstention coverage from AR-038. These are measurements against **hand-authored fictional expectations**, not independent medical ground truth or patient-care validation. Human review is still required for all supported judgments.

Test: `python -m unittest discover -s tests -v`.
