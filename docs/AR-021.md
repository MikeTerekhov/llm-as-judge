# AR-021 — Inter-rater reliability for synthetic reviews

Adds pairwise Cohen's kappa for reviewer pairs with overlapping examples, classic Fleiss' kappa when every multiply-reviewed example has an equal number of ratings, and per-category dispute counts. Empty, degenerate, and unequal-rater cases return null where appropriate rather than false zeroes.

`GET /api/v1/judge/reliability` is disabled by default. Operators may enable it locally using `AI_REGIMEN_ENABLE_REVIEW_API=true` and `AI_REGIMEN_REVIEW_PATH=local/reviews.jsonl`, the same settings as AR-020. No model calls or raw reviewer notes are returned.

Important: reviewer IDs are pseudonymous and self-asserted, there is no endpoint authentication, and the local JSONL storage is not safe for public deployment or concurrent editing. Kappa measures inter-rater consistency, not validity of a clinical claim. Small sample sizes and imbalanced labels can make kappa unstable or undefined.
