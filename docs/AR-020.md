# AR-020 — Human adjudication for fictional fixtures

Adds a local-only review CLI for the twelve fictional adversarial examples. Each pseudonymous reviewer can submit one semantic label per example. Reports distinguish missing second reviews, unanimous agreement and disputes. There is no automatic tie-breaker or model-based adjudication.

Example:
```bash
python -m scripts.review_synthetic_case --example negation-reversal --reviewer reviewer_1 --label contradicted
python -m scripts.review_synthetic_case --example negation-reversal --reviewer reviewer_2 --label supported
python -m scripts.review_synthetic_case --report
```

Review records are stored in ignored `local/reviews.jsonl`. They contain synthetic example IDs, pseudonymous reviewer IDs, labels, short notes and timestamps. **Do not enter personal data, patient information or confidential notes.** This is not an authenticated multiuser service: reviewer IDs are self-asserted, files are unencrypted, and concurrent writes are not safe. Run only in a trusted local environment. Unanimity is not clinical accuracy or independent validation.
