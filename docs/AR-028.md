# AR-028 — Research release manifest

Produces a local, checksum-verified JSON manifest connecting a 40-character Git commit identifier, the AR-023 synthetic evaluation report, review-count fingerprint, AR-027 readiness result, regression baseline and a manual decision. The default decision is `pending`. An `approved` decision is rejected unless the report is ready for manual research review; `rejected` requires a pseudonymous reviewer identifier.

```bash
python -m scripts.create_release_manifest --report local/evaluation-report.json --regression artifacts/evaluation-regression.json --commit-sha <40-character-commit-sha> --output local/release-manifest.json
```

For local review records, specify `--reviewer-id reviewer1 --approval rejected` (or approved only after all readiness checks pass). These are self-asserted annotations, **not authenticated approvals**. Neither the manifest checksum nor the commit SHA string proves provenance or reviewer identity. No deployment, GitHub release, model invocation, clinical validation, or medical decision is performed. Store manifests in an access-controlled research environment.
