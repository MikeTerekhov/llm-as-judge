# AR-026 — Synthetic evaluation history dashboard

Store checksum-verified, immutable local snapshots of AR-023 synthetic evaluation reports and inspect changes between adjacent snapshots. The filename is the snapshot identifier, so choose lexicographically sortable names such as `20261118_abcdef12`. The history loader verifies each checksum, limits the number of files and rejects symlinks or oversized reports. It exposes only summary metadata, not reviewer notes or source records.

```bash
python -m scripts.generate_evaluation_report --output local/evaluation-report.json
python -m scripts.snapshot_evaluation_report --report local/evaluation-report.json --snapshot 20261118_abcdef12
```

For local-only UI access set `AI_REGIMEN_ENABLE_EVALUATION_HISTORY_API=true` and `AI_REGIMEN_EVALUATION_HISTORY_DIR=local/evaluation-history`. View `/judge/evaluation-history`. The read-only endpoint is unauthenticated and disabled by default: never expose it publicly.

History is sorted by snapshot name, not verified Git commit ancestry. Snapshot names and report checksums are not authenticated provenance. Regression detection reports differences, not clinical correctness. The report's blocked review-quality status is expected if no human reviews exist.
