# AR-002 — Versioned clinical evidence retrieval foundation

Research-only, synthetic fixtures. No clinical recommendations.

## Implemented
- Offline evidence snapshots with source URL, publication date, retrieval timestamp, version, and SHA-256 content integrity.
- HTTPS hostname allowlist for NIH HIV guidance and FDA.
- Deterministic paragraph keyword search with source metadata.
- Fail-closed behavior for stale, future-dated, unmatched, or tampered snapshots.
- Eight unit tests with entirely synthetic text.

## Important limitations
This is **not live guideline ingestion**. Hashes detect modification after record creation; they do not authenticate the claimed source or prove medical accuracy. A URL allowlist does not verify the passage's origin. No real patient data, diagnosis, drug selection, or clinical deployment is supported. Retrieved passages must be treated as untrusted data, not model instructions.

Next: implement an auditable, allowlisted HTTPS ingestion pipeline, source verification, clinician content review, and scheduled freshness checks before any clinical use.

## Snapshot schema
JSON array with fields: document_id, title, url, version, published_on (YYYY-MM-DD), retrieved_at (timezone-aware ISO 8601), content, sha256_digest (SHA-256 of UTF-8 content).
