# AR-034 — Optional live lexical evaluator in guided demo

The guided demo's Evaluation step now offers **Connect actual evaluator**, which fetches the existing read-only `GET /api/v1/judge/adversarial` endpoint. It displays the twelve canonical fictional adversarial cases, real deterministic lexical screening statuses, token coverage, and potential false-assurance flags. The separate offline table remains an explicitly illustrative simulation.

## Run

From the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-api.txt
python -m uvicorn api.app:app --reload --port 8000
```

In another terminal:

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000/demo`, choose **Evaluation**, and click **Connect actual evaluator**. If the backend is unavailable, the UI shows a connection error and retains the offline demo. The connection is user-initiated, read-only, and times out after five seconds. Exported JSON records whether live screening was connected and its aggregate metrics.

This is deterministic lexical screening, **not** an LLM call, semantic correctness guarantee, clinical validation, or prescribing system. No user text is submitted to the endpoint. No medical records or external services are used.
