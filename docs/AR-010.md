# AR-010 — Claim-grounding screening

Adds a deterministic claim evaluator for synthetic research workflows. The judge checks citation identifiers and whether meaningful claim tokens appear in cited evidence excerpts. It returns `abstain`, `flagged`, or `review_required` with missing terms and reasons.

**Important:** `review_required` does not mean supported, entailed, safe, clinically accurate, or approved. Token overlap is not semantic entailment; negation, qualifiers, dose context, tables, and contradictions can fool lexical screening. No external LLM, automatic recommendations, or clinical approval are enabled. The API continues to abstain by default.

Run `python -m unittest discover -s tests -v`. Future work: a separately evaluated model judge, synthetic benchmark with adversarial contradiction examples, calibration, and independent human adjudication before any stronger claim.
