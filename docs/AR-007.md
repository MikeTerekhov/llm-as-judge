# AR-007 — Reviewed evidence in the research dashboard

The API can now read **locally configured**, manually reviewed evidence snapshots.
It never fetches guidelines in an HTTP request and never generates clinical recommendations.

Set both environment variables before starting uvicorn:
```bash
export AI_REGIMEN_SNAPSHOT_PATH=/absolute/path/to/local-guideline-snapshot.json
export AI_REGIMEN_REVIEW_PATH=/absolute/path/to/local-guideline-review.json
```

Endpoints:
- `GET /api/v1/evidence?query=monitoring`: matching reviewed evidence metadata and excerpt
- `POST /api/v1/cases/assess`: existing completeness/evidence gates, still abstains because no claim generator is enabled

Both files must exist; malformed configured files return an error instead of silently treating the content as verified. Without configuration, the index is empty.

The dashboard displays source title, version, publication date, retrieval date, digest and excerpt. An operator's self-attested review is **not** source authentication or clinical approval. Do not load real patient data. HTML extraction may lose tables and footnotes. The evidence search uses keyword overlap, not semantic or clinical validation. No authentication or production hardening is included.

Run:
```bash
python -m unittest discover -s tests -v
cd frontend && npm run build
```
