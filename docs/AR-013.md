# AR-013 — Read-only judge evaluation dashboard

Adds GET /api/v1/judge/benchmark and /judge UI route for the six static synthetic benchmark fixtures. The API exposes category metrics, confusion counts, individual lexical screening decisions, missing tokens and explanations. No arbitrary user claims are accepted and no external LLM is invoked.

This milestone does NOT yet compare model-vs-baseline disagreement rates. That requires explicit opt-in model configuration and a separately adjudicated dataset. The displayed fixture accuracy is circular by design: expected labels encode the deterministic screener's intended behavior. It must not be presented as clinical, semantic or real-world accuracy.

Run Python tests with `python -m unittest discover -s tests -v`, start the FastAPI server and Next.js app, then open `/judge`.
