# AR-022 — Benchmark quality gates

Adds conservative review-process gates for the twelve fictional adversarial fixtures: minimum one-review coverage, minimum double-review coverage, maximum fraction of disputed multiply-reviewed cases, and minimum defined pairwise Cohen kappa. Defaults require 100% review and double-review coverage, zero disputes and pairwise kappa >= 0.6. Undefined kappa always blocks the dataset.

Run `python -m scripts.check_benchmark_quality --history local/reviews.jsonl`. The command emits JSON and exits nonzero when gates fail. Thresholds can be adjusted via CLI flags; a relaxed policy must be explicitly documented in research reporting.

`GET /api/v1/judge/quality-gates` uses the same opt-in local review settings as AR-020/021. It is disabled by default and is not authenticated; do not expose publicly.

These checks measure annotation completeness and reviewer consistency, not correctness or medical validity. The review source is unencrypted local JSONL, reviewer identities are self-asserted, and no patient information is allowed.
