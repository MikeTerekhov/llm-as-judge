# AR-017 — Synthetic experiment analytics

Adds a read-only `GET /api/v1/judge/experiments` endpoint and a `/judge/history` dashboard page with per-run disagreement trends and weighted model comparisons. History comes from local AR-016 metadata-only JSONL records.

The history API is **disabled by default**. Operators must set `AI_REGIMEN_ENABLE_HISTORY_API=true` and `AI_REGIMEN_HISTORY_PATH=local/experiments.jsonl` to enable it. The endpoint returns only run metadata and aggregates, never raw model prompts, source excerpts, keys or rationales.

Important: The API currently has no authentication and should not be enabled on a public deployment. Run it only on a trusted, access-controlled local environment. Model identifiers and run metadata may still be sensitive. No LLM calls occur when viewing history. Disagreement is not a clinical correctness metric.
