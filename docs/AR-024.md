# AR-024 — Automated synthetic evaluation CI

The GitHub Actions workflow now runs an independent, offline evaluation job after checkout and Python setup. It generates the deterministic AR-023 synthetic report twice, checks identical output and SHA-256 integrity, verifies the saved JSON round-trip, and uploads the JSON as a GitHub Actions artifact with 14-day retention.

Run locally:

```bash
python -m scripts.verify_evaluation_ci --output artifacts/synthetic-evaluation.json
python -m unittest discover -s tests -v
```

The CI report intentionally contains **zero human reviews**. Quality gates are therefore **blocked**, and this is asserted as the correct, fail-closed outcome. CI fails on broken generation, checksum mismatch, nondeterminism, or unexpected review content, **not** because a synthetic dataset lacks human validation.

The uploaded artifact is fictional research metadata, not a clinical validation result. The job makes no model calls and needs no secrets. Do not upload local reviewer files or patient data. For reproducibility across code revisions, retain the associated GitHub Actions commit SHA and artifact run ID.
