# AR-043 — Browser-local experiment history dashboard

Open `/judge/experiment-history` and select the JSON file created by AR-042's `python -m scripts.experiment_history add ...` CLI. The page reads the selected file locally in the browser. It does not make API requests, invoke LLMs, or automatically read files from the backend.

The dashboard provides model filters, chronological agreement bars, verdict coverage, conditional authored-label agreement, macro F1, and per-fixture verdict inspection. Reports must have schema version 1, at most 200 runs, a maximum 2 MiB file size, and 12 unique matching fictional fixtures per run. The browser validates report structure but does not independently verify the history SHA-256 checksum or the fixture IDs against a server-side reference. For integrity checks, use the AR-042 Python CLI.

No real model runs are bundled or invented. Agreement with fictional hand-authored labels is not clinical correctness or a statistically meaningful model ranking. Do not import patient data.

Test with `cd frontend && npm run build` and `python -m unittest discover -s tests -v`.
