# AR-019 — Adversarial LLM benchmarking

Adds a comparison evaluator for twelve fictional, hand-authored semantic examples, with model verdict agreement, lexical/model operational disagreement and per-category rates. Missing/failed model results are reported as abstentions, not silently counted as correct.

The read-only `GET /api/v1/judge/adversarial-model` endpoint is offline and shows the unconfigured status. For a live operator-run experiment, first configure the AR-015 opt-in environment variables and run `python -m scripts.run_adversarial_model_benchmark`. No API keys are stored in source control. Never use patient information.

Labels are synthetic and not independently adjudicated. Rates measure agreement with fixture authors, **not clinical accuracy**. Model supported verdicts remain subject to human review. The operator CLI does not persist raw model responses or prompts.
