# AR-004 — Synthetic research dashboard

Adds FastAPI endpoints and a Next.js dashboard on top of AR-001–003.

## Run locally

Backend (from repository root):
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-api.txt
uvicorn api.app:app --reload --host 127.0.0.1 --port 8000
```

Frontend (in another terminal):
```bash
cd frontend
npm install
npm run dev
```
Open http://localhost:3000.

## API
- GET /health
- POST /api/v1/cases/review: completeness warnings
- POST /api/v1/cases/assess: abstains by default, because no verified live evidence is configured

## Safety and limitations
Only synthetic demo data is permitted. The synthetic flag and SYN- case ID are declarations, not PHI detection. Never enter real patient data. No authentication, persistence, medical rule engine, live evidence, model inference, or deployment hardening is provided. CORS is restricted to localhost:3000 for development. Do not expose this service publicly or use for patient care.

## Test

python -m unittest discover -s tests -v
