# AR-040 — Offline model comparison

Compare two or more AR-039 executed JSON reports on the same twelve fictional adversarial fixtures:

```bash
python -m scripts.compare_model_runs run-model-a.json run-model-b.json --output comparison.json
```

The comparison is offline and does not invoke external models. Input files must each be under 1 MiB, contain twelve distinct fixture identifiers, and have matching identifiers and authored expected labels across runs. Dry runs are rejected. Existing output files are not overwritten.

Each run reports verdict coverage, abstentions, and conditional agreement with fictional authored labels. Every pair reports the number of shared returned verdicts, disagreement on that shared subset, and each model's agreement on the same shared subset. A pair with no shared verdicts has null disagreement and agreement rates. Different coverage is shown explicitly, so selective abstention cannot silently inflate a head-to-head comparison.

This is descriptive comparison only. The authored labels are not independent clinical ground truth, and twelve examples are insufficient for claims of general model superiority. Model identifiers are labels from local reports, not independently verified provider provenance. No API route, dashboard auto-execution, or patient data is involved.

Verify with `python -m unittest discover -s tests -v`.
